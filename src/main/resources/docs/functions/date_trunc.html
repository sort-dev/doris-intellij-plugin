DATE_TRUNC(datetime, time_unit)
DATE_TRUNC(time_unit, datetime)

Apache Doris：将日期或时间截断到指定单位，低于该单位的部分归零（日期部分取该周期起点）。

参数

  • datetime：DATE、DATETIME 或可转换的日期时间表达式。
  • time_unit：字符串常量，可选 second、minute、hour、day、week、month、quarter、year。

返回值：截断后的日期或时间；DATE 输入返回 DATE，DATETIME 输入返回 DATETIME。任一参数为 NULL 时返回 NULL；不支持的时间单位报错。

示例

SELECT DATE_TRUNC('2026-01-15', 'month');
SELECT DATE_TRUNC('month', '2026-01-15');
-- 结果：2026-01-01
