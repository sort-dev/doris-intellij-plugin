BIT_LENGTH

描述

返回字符串或二进制值的位数。

语法

BIT_LENGTH( <str>)

参数

  • <str> 需要计算位数的字符串值。

返回值

返回 <str> 的二进制表示所占的位数，包括其中的所有 0 和 1。

示例

  1. 示例 1

    select BIT_LENGTH("abc"), BIT_LENGTH("中国"), BIT_LENGTH(123);

    +-------------------+----------------------+-----------------+
| BIT_LENGTH("abc") | BIT_LENGTH("中国")   | BIT_LENGTH(123) |
+-------------------+----------------------+-----------------+
|                24 |                   48 |              24 |
+-------------------+----------------------+-----------------+

  2. NULL 参数

    select BIT_LENGTH(NULL);

    +------------------+
| BIT_LENGTH(NULL) |
+------------------+
|             NULL |
+------------------+
