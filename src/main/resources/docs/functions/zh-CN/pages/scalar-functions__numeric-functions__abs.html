ABS

描述

返回一个值的绝对值。

语法

ABS(<x>)

参数

参数 说明
<x> 需要被计算绝对值的值

返回值

参数 x 的绝对值，当 x 为 NULL 时，返回 NULL

举例

select abs(-2);

+---------+
| abs(-2) |
+---------+
|       2 |
+---------+

select abs(3.254655654);

+------------------+
| abs(3.254655654) |
+------------------+
|      3.254655654 |
+------------------+

select abs(-3254654236547654354654767);

+---------------------------------+
| abs(-3254654236547654354654767) |
+---------------------------------+
| 3254654236547654354654767       |
+---------------------------------+

select abs(NULL);

+-----------+
| abs(NULL) |
+-----------+
|      NULL |
+-----------+
