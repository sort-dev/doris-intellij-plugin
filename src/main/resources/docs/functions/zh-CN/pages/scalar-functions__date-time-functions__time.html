TIME | Date Time Functions

TIME

描述

TIME 函数可以获取一个DateTime值的 time 部分.

语法

TIME(<datetime>)

参数

参数 描述
<datetime> 一个datetime值.

返回值

返回TIME类型的值

举例

SELECT TIME('2025-1-1 12:12:12');

mysql> 
+---------------------------+
| time('2025-1-1 12:12:12') |
+---------------------------+
| 12:12:12                  |
+---------------------------+
