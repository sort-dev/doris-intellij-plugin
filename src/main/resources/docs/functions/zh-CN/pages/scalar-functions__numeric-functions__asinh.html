ASINH

描述

返回x的反双曲正弦值。

语法

ASINH(<x>)

参数

参数 描述
<x> 需要计算反双曲正弦值的数值

返回值

参数x的反双曲正弦值。

特殊情况

  • 当 x 为 NaN，返回 NaN
  • 当 x 为正无穷，返回 Infinity
  • 当 x 为负无穷，返回 -Infinity
  • 当 x 为 NULL，返回 NULL

示例

select asinh(0.0);

+------------+
| asinh(0.0) |
+------------+
|          0 |
+------------+

select asinh(1.0);

+-------------------+
| asinh(1.0)        |
+-------------------+
| 0.881373587019543 |
+-------------------+

select asinh(-1.0);

+--------------------+
| asinh(-1.0)        |
+--------------------+
| -0.881373587019543 |
+--------------------+

select asinh(cast('nan' as double));

+------------------------------+
| asinh(cast('nan' AS DOUBLE)) |
+------------------------------+
| NaN                          |
+------------------------------+

select asinh(cast('inf' as double));

+------------------------------+
| asinh(cast('inf' AS DOUBLE)) |
+------------------------------+
| Infinity                     |
+------------------------------+

select asinh(cast('-inf' as double));

+-------------------------------+
| asinh(cast('-inf' AS DOUBLE)) |
+-------------------------------+
| -Infinity                     |
+-------------------------------+
