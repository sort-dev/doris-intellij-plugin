NEGATIVE

描述

返回传参 x 的负值

语法

NEGATIVE(<x>)

参数

参数 说明
<x> 自变量 支持类型BIGINT DOUBLE DECIMAL

返回值

返回整型或者浮点数。特殊情况：

  • 当参数为 NULL 时，返回 NULL
  • 当参数为 0 时，返回 0

注意对于整数，负数的绝对值范围大于正数的绝对值范围，Doris 不会处理这种特殊情况。

举例

SELECT negative(-10);

+---------------+
| negative(-10) |
+---------------+
|            10 |
+---------------+

SELECT negative(12);

+--------------+
| negative(12) |
+--------------+
|          -12 |
+--------------+

SELECT negative(0);

+-------------+
| negative(0) |
+-------------+
|           0 |
+-------------+

SELECT negative(null);

+----------------+
| negative(NULL) |
+----------------+
|           NULL |
+----------------+
