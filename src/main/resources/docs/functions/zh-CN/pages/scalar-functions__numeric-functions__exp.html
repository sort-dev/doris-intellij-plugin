EXP

描述

返回以e为底的x的幂。

别名

  • DEXP

语法

EXP(<x>)

参数

参数 说明
<x> 自变量

返回值

返回一个 double。特殊情况：

  • 当参数为NULL时，返回 NULL

  • 当参数为比较大的时候，返回 Infinity

举例

select exp(2);

+------------------+
| exp(2.0)         |
+------------------+
| 7.38905609893065 |
+------------------+

select exp(3.4);

+--------------------+
| exp(3.4)           |
+--------------------+
| 29.964100047397011 |
+--------------------+

select exp(1000000);

+--------------+
| EXP(1000000) |
+--------------+
|     Infinity |
+--------------+
