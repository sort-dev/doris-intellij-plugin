ARRAY_SUM

功能

ARRAY_SUM 函数用于对数组中的所有数值元素求和。

语法

ARRAY_SUM(ARRAY<T>)

参数

ARRAY<T>：一个包含数值类型元素的数组。

返回值

  • 返回数组中所有非 NULL 元素的总和。

    • 如果全是 NULL，返回 NULL。

使用说明

  1. 元素的求和使用 + 运算符。

  2. 对于包含 NULL 的元素，会自动忽略这些元素。

  3. 如果数组包含非数值类型元素（如字符串），将导致运行错误。

示例

  1. 简单示例

    SELECT ARRAY_SUM([1, 2, 3, 4]);
+-------------------------+
| ARRAY_SUM([1, 2, 3, 4]) |
+-------------------------+
|                      10 |
+-------------------------+

  2. 数组中的 NULL 处理

    SELECT ARRAY_SUM([1, NULL, 3]); 
+-------------------------+
| ARRAY_SUM([1, NULL, 3]) |
+-------------------------+
|                       4 |
+-------------------------+

SELECT ARRAY_SUM(NULL);
+-----------------+
| ARRAY_SUM(NULL) |
+-----------------+
|            NULL |
+-----------------+

SELECT ARRAY_SUM([NULL, NULL]); 
+-------------------------+
| ARRAY_SUM([NULL, NULL]) |
+-------------------------+
|                    NULL |
+-------------------------+
