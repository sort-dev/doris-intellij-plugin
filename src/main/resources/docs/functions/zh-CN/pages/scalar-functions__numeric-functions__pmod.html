PMOD

描述

返回模运算 x mod y 在模系中的最小正数解，即通过计算 (x % y + y) % y 得出结果。

语法

PMOD(<x> , <y>)

参数

参数 说明
<x> 被除数
<y> 除数 不能为 0

返回值

返回一个整型或浮点数。特殊情况：

  • 当 x=0 时，返回 0。
  • 当 x is NULL 或 y is NULL 时，返回 NULL。

举例

SELECT PMOD(13,5);

+-------------+
| pmod(13, 5) |
+-------------+
|           3 |
+-------------+

SELECT PMOD(-13,5);

+--------------+
| pmod(-13, 5) |
+--------------+
|            2 |
+--------------+

SELECT PMOD(0,-12);

+--------------+
| pmod(0, -12) |
+--------------+
|            0 |
+--------------+

SELECT PMOD(0,null);

+-------------------------------+
| pmod(cast(0 as DOUBLE), NULL) |
+-------------------------------+
|                          NULL |
+-------------------------------+
