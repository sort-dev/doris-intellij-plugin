POSITIVE

描述

返回数值本身。

语法

POSITIVE(<x>)

参数

参数 说明
<x> 需要返回的数值

返回值

返回一个整型或者浮点数。特殊情况：

  • 当 x is NULL 时，返回 NULL

举例

SELECT positive(-10);

+---------------+
| positive(-10) |
+---------------+
|           -10 |
+---------------+

SELECT positive(10.111);

+------------------+
| positive(10.111) |
+------------------+
|           10.111 |
+------------------+

SELECT positive(12);

+--------------+
| positive(12) |
+--------------+
|           12 |
+--------------+

SELECT positive(null);

+----------------+
| positive(NULL) |
+----------------+
|           NULL |
+----------------+
