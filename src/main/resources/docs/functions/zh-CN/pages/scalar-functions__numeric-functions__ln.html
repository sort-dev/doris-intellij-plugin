LN

描述

返回以e为底的x的自然对数。

别名

  • DLOG1

语法

LN(<x>)

参数

参数 说明
<x> 真数 必须大于 0

返回值

返回一个浮点数。特殊情况：

  • 当 x 为 NULL 时，返回NULL
  • 当 x 为 NaN 时，返回 NaN
  • 当 x 为正无穷大或负无穷大时，返回 NULL
  • 当 x 为 NULL 时，返回 NULL

举例

select ln(1);

+-----------------------+
| ln(cast(1 as DOUBLE)) |
+-----------------------+
|                   0.0 |
+-----------------------+

select ln(e());

+---------+
| ln(e()) |
+---------+
|     1.0 |
+---------+

select ln(10);

+------------------------+
| ln(cast(10 as DOUBLE)) |
+------------------------+
|      2.302585092994046 |
+------------------------+

select ln(cast('inf' as double));

+---------------------------+
| ln(cast('inf' as double)) |
+---------------------------+
|                  Infinity |
+---------------------------+

select ln(cast('nan' as double));

+---------------------------+
| ln(cast('nan' as double)) |
+---------------------------+
|                       NaN |
+---------------------------+
