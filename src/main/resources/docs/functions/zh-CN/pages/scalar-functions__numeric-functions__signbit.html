SIGNBIT

描述

判断给定浮点数的符号位是否为负。

语法

SIGNBIT(<a>)

参数

参数 说明
<a> 要检查的浮点数参数

返回值

如果 <a> 的符号位为负（即 <a> 是负数），返回 true，否则返回 false。 特别的，对于浮点数的正负零，也可以区分。

示例

select signbit(-1.0);

+---------------+
| signbit(-1.0) |
+---------------+
|             1 |
+---------------+

select signbit(0.0);

+--------------+
| signbit(0.0) |
+--------------+
|            0 |
+--------------+

select signbit(1.0);

+--------------+
| signbit(1.0) |
+--------------+
|            0 |
+--------------+

select signbit(cast('+0.0' as double)) , signbit(cast('-0.0' as double));

+---------------------------------+---------------------------------+
| signbit(cast('+0.0' as double)) | signbit(cast('-0.0' as double)) |
+---------------------------------+---------------------------------+
|                               0 |                               1 |
+---------------------------------+---------------------------------+
