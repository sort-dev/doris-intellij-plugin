CRC32

描述

使用 CRC32 算法计算结果。

语法

CRC32( <str> )

参数

参数 说明
<str> 需要被计算 CRC 的值

返回值

返回字符串的 CRC 值。

示例

select crc32("abc"),crc32("中国");

+--------------+-----------------+
| crc32('abc') | crc32('中国')   |
+--------------+-----------------+
|    891568578 |       737014929 |
+--------------+-----------------+
