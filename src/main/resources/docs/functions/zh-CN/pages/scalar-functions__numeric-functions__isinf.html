ISINF

描述

判断指定的值是否为无穷大。

语法

ISINF(<value>)

参数

参数 说明
<value> 要检查的值，DOUBLE 或 FLOAT 类型

返回值

如果值是无穷大（正无穷或负无穷），则返回 1，否则返回 0。 如果值为 NULL，则返回 NULL。

示例

SELECT isinf(1);

+----------+
| isinf(1) |
+----------+
|        0 |
+----------+

SELECT cast('inf' as double),isinf(cast('inf' as double))

+-----------------------+------------------------------+
| cast('inf' as double) | isinf(cast('inf' as double)) |
+-----------------------+------------------------------+
|              Infinity |                            1 |
+-----------------------+------------------------------+

SELECT isinf(NULL)

+-------------+
| isinf(NULL) |
+-------------+
|        NULL |
+-------------+
