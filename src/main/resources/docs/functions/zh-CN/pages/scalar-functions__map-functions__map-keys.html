MAP_KEYS

描述

将给定 map 的键提取成一个对应类型的 ARRAY。

语法

MAP_KEYS(<map>)

参数

  • <map> MAP 类型，输入的 map 内容。

返回值

将给定 map 的键提取成一个对应类型的 ARRAY。

举例

  1. 常规参数
    select map_keys(map()),map_keys(map(1, "100", 0.1, 2, null, null));

    +-----------------+---------------------------------------------+
| map_keys(map()) | map_keys(map(1, "100", 0.1, 2, null, null)) |
+-----------------+---------------------------------------------+
| []              | [1.0, 0.1, null]                            |
+-----------------+---------------------------------------------+
  2. NULL 参数
    select map_keys(NULL);

    +----------------+
| map_keys(NULL) |
+----------------+
| NULL           |
+----------------+
