ISNAN

描述

判断指定的值是否为 NaN（非数字）。

语法

ISNAN(<value>)

参数

参数 说明
<value> 要检查的值，DOUBLE 或 FLOAT 类型

返回值

如果值是 NaN，则返回 1，否则返回 0。 如果值为 NULL，则返回 NULL。

示例

SELECT isnan(1);

+----------+
| isnan(1) |
+----------+
|        0 |
+----------+

SELECT cast('nan' as double),isnan(cast('nan' as double));

+-----------------------+------------------------------+
| cast('nan' as double) | isnan(cast('nan' as double)) |
+-----------------------+------------------------------+
|                   NaN |                            1 |
+-----------------------+------------------------------+

SELECT isnan(NULL)

+-------------+
| isnan(NULL) |
+-------------+
|        NULL |
+-------------+
