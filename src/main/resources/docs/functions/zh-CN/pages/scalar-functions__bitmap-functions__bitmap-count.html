BITMAP_COUNT

描述

计算输入 BITMAP 的元素个数

语法

BITMAP_COUNT(<bitmap>)

参数

参数 说明
<bitmap> BITMAP 集合

返回值

返回一个整数

举例

select bitmap_count(to_bitmap(1)) cnt;

+------+
| cnt  |
+------+
|    1 |
+------+

select bitmap_count(bitmap_empty()) cnt;

+------+
| cnt  |
+------+
|    0 |
+------+
