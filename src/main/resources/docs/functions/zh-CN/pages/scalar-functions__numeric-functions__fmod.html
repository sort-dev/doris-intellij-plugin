FMOD

描述

求浮点数类型，a / b 的余数，整数类型请使用 mod 函数。

语法

MOD(<col_a> , <col_b>)

参数

参数 说明
<col_a> 被除数
<col_b> 除 数 不能为 0

返回值

返回一个浮点数。特殊情况：

  • 任意一个输入参数为 NULL 时，返回 NULL。

举例

select fmod(10.1, 3.2);

+--------------------+
| fmod(10.1, 3.2)    |
+--------------------+
| 0.4999999999999991 |
+--------------------+

select fmod(10.1, 0);

+---------------+
| fmod(10.1, 0) |
+---------------+
|          NULL |
+---------------+

select fmod(10.1, NULL);

+------------------+
| fmod(10.1, NULL) |
+------------------+
|             NULL |
+------------------+
